# Bardhi Vula — Portfolio

A responsive portfolio for banking technology, software implementation, and DevOps work. Built with HTML, CSS, and a small JavaScript enhancement. No package installation, API keys, or backend required.

## Preview

Open `dist/index.html` in a browser. The website and CV download work locally.

## Repository

https://github.com/Bardhvula/portofolio

```bash
git clone https://github.com/Bardhvula/portofolio.git
cd portofolio
```

## Deploy on Vercel

1. Open https://vercel.com/new and import the repository.
2. Use the repository root as Root Directory.
3. Choose framework preset **Other**.
4. Leave the Build Command empty; Output Directory is **dist** (also set in `vercel.json`).
5. No environment variables are needed. Click Deploy.

Use your project's production domain when sharing the site. Check deployment protection settings if visitors encounter a Vercel login prompt.

Official documentation: https://vercel.com/docs/git/vercel-for-github and https://vercel.com/docs/project-configuration

## Edit content

- `dist/index.html`: experience, selected work, contact links, and search metadata.
- `dist/styles.css`: colors, typography, and responsive layouts.
- `dist/script.js`: current footer year.
- `dist/Bardhi-Vula-CV.docx`: downloadable resume, copied from the supplied resume on file.
- `vercel.json`: deployment output directory and response headers.

LinkedIn and contact details were taken from the resume. Selected work describes contributions, not independently owned products. Update the CV file when your resume changes. This is a standalone portfolio.

## Validation

Local asset paths, section anchors, contact URLs, JavaScript syntax, JSON configuration, and the DOCX archive were checked. Browser rendering and live Vercel deployment were not tested.
